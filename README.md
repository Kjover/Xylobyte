# XyloByte

XyloByte is a small web app that turns your keyboard into a virtual xylophone.

## How it works

There are eight notes that can be played by clicking the xylophone bars or using the keyboard. A, S, D, F, G, H, J and K each play a different note.

The app uses HTML, CSS and JavaScript with the Web Audio API to create the sounds.

## SHRINK

This project was made for the SHRINK hackclub program. The final version is a single data:text/html URI that is under 3,072 bytes.

## Files

src/index.html is the readable version of the app.

build.mjs builds the final version.

dist/uri.txt contains the final data URI.
